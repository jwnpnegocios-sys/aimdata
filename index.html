Histórico de Partidas

Filtro por Mapa — o filtro de mapa é compartilhado com o Dashboard. Clique no pill para selecionar um mapa específico. "Todos os mapas" remove o filtro.

Métricas — clique no pill para mostrar ou ocultar métricas. As colunas da tabela se adaptam automaticamente.

Ordenação — clique nos cabeçalhos de coluna para ordenar. Clique novamente para inverter (crescente ↔ decrescente).

Edição Inline — clique em ✎ para editar data, hora, mapa, métricas e anotações diretamente na tabela. Os valores calculados se atualizam automaticamente.

Duplicar — ⧉ cria uma cópia da partida com data/hora atual e novo número. Útil para partidas seguidas com resultados parecidos.

Excluir — ✕ remove permanentemente. Não há desfazer.

Anotações — 📝 indica observação. Passe o mouse para ler sem editar.

Scroll — em telas pequenas, arraste horizontalmente para ver todas as colunas.
